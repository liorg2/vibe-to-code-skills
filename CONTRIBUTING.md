# Contributing

Thanks for helping. Keep changes small and focused.

- **Fix or improve a skill:** open a pull request against `main`. Edit the English `SKILL.md` and, if you can, the Hebrew `SKILL.he.md` to match. If you can't, say so in the PR.
- **Keep the voice:** short, friendly, plain words. Skills ask only what they can't find in the project, and never push, pay or publish without asking.
- **Never** put real keys, tokens or personal data in a skill or an example.
- **New skill or big change?** Open an issue first so we can agree on it.

Every pull request is reviewed and merged by the maintainer. Changes on `main` go live on [vibetodev.com](https://www.vibetodev.com) with the next site build.
